## 所需环境

| 模组 | 版本 |
|---|---|
| Minecraft | 1.20.1 |
| Java | 17 或更高 |
| [Fabric Loader](https://fabricmc.net/use/) | 0.15 或更高 |
| [Fabric API](https://modrinth.com/mod/fabric-api) | 任意适用于 1.20.1 的版本（开发时使用 0.92.12+1.20.1） |
| [GeckoLib](https://modrinth.com/mod/geckolib) | 适用于 1.20.1 的 4.8.4 或更高版本（用于带动画的怪物、首领和机械装置） |
| [playerAnimator](https://modrinth.com/mod/playeranimator) | 适用于 1.20.1 的 1.0.2-rc1+1.20 或更高版本（用于玩家攻击动画） |

这四个模组缺一不可：缺少任何一个，游戏都无法启动。[Mod Menu](https://modrinth.com/mod/modmenu) 是可选的，它只会显示本模组的简介。Embervoid 没有游戏内配置界面，设置都保存在文件里（参见[配置](configuration.md)）。

## 单人游戏

1. 安装适用于 1.20.1 的 Fabric Loader。
2. 把 Embervoid、Fabric API、GeckoLib 和 playerAnimator 放进 `mods` 文件夹。
3. 启动游戏，创建新世界，或打开已有世界。Embervoid 可以用在旧的原版世界里，但它的地下遗迹只会出现在你装上模组之后才生成的区块中。

## 专用服务器

在服务器**和**每个客户端上安装同样的四个模组。没有安装模组的客户端无法加入。

以服务器上的 `config/embervoid.json` 为准：玩家加入时它会发送给每个人，客户端在本次游戏中按它执行。仅限客户端的设置（精力条、怪物等级标签、首领音乐音量、镜头震动）由各玩家自己保存。

## 更新到新版本

先备份存档，再替换 jar 文件。Embervoid 会在新版本首次启动时升级存档。

- **从 0.5.0–0.5.2 升级到 0.5.3，以及从 0.4.x 升级到 0.5.x：** 领域灰烬边域会按新的布局重新生成。你的进度会保留（已击败的首领、已解锁和已完成的领域），遗留在领域中的灰烬遗骸会被放到余烬圣所的抵达平台上，在领域内下线的玩家会在余烬圣所上线。你在灰烬边域内建造的东西、留在箱子里的东西都会消失，你休息过的领域祭坛也会被遗忘：你要从抵达平台重新开始。主世界、下界、末地和余烬圣所不会受到影响。
- **从 0.4.x 升级：** 已经生成的圣所保留原来带有灰烬圣女和方尖碑的核心，它们依然可用。新的荒废圣所会出现在新生成的区块中。
- **配置：** 缺失的键会以默认值补上。你已有的键保持原值，即使新版本改了默认值（0.5.3 调整了武器特殊攻击）。删除某个键即可采用新的默认值。
